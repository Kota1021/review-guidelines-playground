# 本質 — SwiftUI

SwiftUI の宣言的・identity ベースの差分更新モデルに由来する特化。[swift.md](./swift.md) と [../principles.md](../principles.md) の上に立つ。

- **描画に影響する入力だけを渡し、その同値判定が描画影響を過不足なく表す** — SwiftUI は view identity と入力の同値性で再描画を判断する。毎回生成される別インスタンス（素のクロージャ・新しい参照）は常に不等となり不要な再描画を招くので、安定した同値性を持たせる。逆に、安定 id だけで同値化すると描画に影響する変化を隠しうるので、同値が描画影響を正しく反映することを確かめる。
- **派生表示を状態に複製しない** — 他の値から導出できる表示は computed property で表し、別の `@State` として二重に持たない。（SSOT の SwiftUI 形。）

> プロジェクト固有の SwiftUI 規約 — クロージャの具体的な包み方、サブ view を `struct: View` に切るか computed `some View` にするか、アクションプロパティの命名、Environment の公開粒度 — は各プロジェクトの規約ドキュメントに置き、レビューはそのドキュメントを読み既存コードを grep して発見する。ここにハードコードしない。これらは上の2原理（入力の同値性・派生の非複製）、共通原理のカプセル化 / 最小知識、命名（名前=実装）の具体化にすぎない。
